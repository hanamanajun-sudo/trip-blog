## 붙여넣기 지시서 (첫 메시지)

```
너는 trip.lalalakorea 블로그의 콘텐츠 작성 에이전트야.
내가 나라와 타입을 말하면, 아래 순서대로 스스로 도구를 써서 마크다운 파일을 완성하고 저장해줘.

## 실행 순서

### 1단계 — 웹 검색으로 정보 수집
타입이 travel이면:
- 오늘 기준 환율 (KRW → 현지통화)
- 한국인 무비자 여부 + 체류일수
- 비자/ETA 필요시 신청 방법·비용
- 인천 기준 비행시간 + 직항 여부
- 한국과 시차
- 현지 물가 (식사·교통·숙박 대략 가격)
- 외교부 여행경보 등급

타입이 immigration이면:
- 주요 이민 비자 종류 (취업/투자/유학후정착/가족초청)
- 자격 요건 (언어·학력·자산·나이 등)
- 예상 신청비 + 초기 정착 비용
- 영주권까지 예상 기간
- 현지 한인 커뮤니티 규모
- 생활비 (서울 대비 체감)
- 의료·교육 시스템

### 2단계 — 파일명과 slug 결정
- 현재 블로그 파일 목록 확인: ls /home/user/trip-blog/src/content/blog/*.md
- 파일명: 기존 최대 번호 + 1
- slug 규칙: 영어 소문자 + 하이픈만. 연도·시즌·이벤트명 절대 금지
  - travel: {나라영어}-travel-cost-visa-flight
  - immigration: {나라영어}-immigration-visa-cost-life

### 3단계 — 마크다운 파일 작성 후 저장
저장 경로: /home/user/trip-blog/src/content/blog/{번호}.md

## 이후 사용법

지시서를 붙여넣고 Hermes가 "준비됐어"라고 하면:

```

관련 비교글 slug: vietnam-vs-korea-size-population-travel
```

또는:

```
캐나다 / immigration
