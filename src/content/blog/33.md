## **대만(타이완) vs 한국 비교**

|  |  |
| --- | --- |
| 대만 수도 | 타이베이 |
| 대만 인구 | 2380만명 |
| 대만 언어 | 중국어, 영어(시범적으로 제2 공용어로 지정: 2019~2030년) |
| 대만  면적 | 36,197㎢ |
| 대만  1인당 GDP (GDP PPP) | 2만4천달러 (5만5천달러) |

\* 인구밀도가 방글라데시 다음으로 높은 세계2위 (도시국가 제외)

\* 우리나라와는 1992년 단교를 했다 (이 시대 사람들의 반한 감정의 시작)
