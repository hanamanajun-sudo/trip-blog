## **콩고민주공화국 vs 한국 비교**

|  |  |
| --- | --- |
| 콩고민주공화국 수도 | 킨샤사 |
| 콩고민주공화국 인구 | 9237만명 |
| 콩고민주공화국 언어 | 프랑스어, 기타 토착어 |
| 콩고민주공화국 면적 | 2,344,858㎢ |
| 콩고민주공화국 1인당 GDP (GDP PPP) | 466달러 (785달러) |

\* 콩고 민주 공화국 영어로 **République démocratique du Congo**

\* 기독교인이 약 80%

\* 남한 보다 약 23배가 크다.

\* 우리나라 교민수는 120명 정도

\* 공용어인 프랑스어는 옛 식민지 통치국 벨기에의 영향을 받음

**\* 내전이 현재도 진행중인 나라이다.**

독재정권의 부패가 발단이 되어 시작하였고  
1996년 부터 2003년까지 주변국 10여개국이 관여하여 400만명이상이 죽었다.

우리나라에는 잘 알려지지 않았지만(우리나라 뿐 아니라 당사국을 제외하면 거의 아는 사람이 없다)

**\* 우리나라에서 가장 유명한 콩고 민주공화국 사람은**

**콩고왕자 가족** (라비 욤비, 조나단 욤비) - 콩고 내전으로 도망쳐 한국에 망명했다.
