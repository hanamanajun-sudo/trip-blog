## **스웨덴 그리고 한국 기본 수치 비교**

## **스웨덴 vs 한국 비교**

|  |  |
| --- | --- |
| 스웨덴 인구 | 1035만명 |
| 스웨덴 수도 | 스톡홀름 |
| 스웨덴 언어 | 스웨덴어 |
| 스웨덴 면적 | 450,295㎢ |
| 스웨덴 1인당 GDP (GDP PPP) | 58,977달러 (55,566달러) |

### **스웨덴 상식**

\* 민주주의 지수가 4위 이다.

\* 유아 교육 부터 대박 학비까지 무료 이다. (자국민 만)

\* 의료비가 일정 금액을 넘어가면 무료이다. (국가지원이라 의사와 병원이 다소 부족하다고 한다.)

\*스웨덴 하면 떠오르는 유명한 것 - 이케아, 미드소마

\* 미드소마는 실제로 스웨덴에 존재하는 여름 축제로 한여름이라는 뜻이다.   
 영화와는 다르게 가족단위의 평화로운 축제 (영화에서도 처음에는 가족단위의 평화로운 축제였지..)

### **스웨덴 논란 (스웨덴 게이트)**

최근 전세계적으로 휩쓸고 간 유명한 이슈가 있었다.

스웨덴에서는 집에 온 손님에게 밥을 안준다는것인데 더욱이 본인 아이의 친구가 놀러와도 안준다는것에 크게 문화 충격을 받고 논란이 있었다.

전세계 사람들이 과거에 받은 문화적인 충격을 받은 경험담을 나누고 그 나라의 문화이다. 아무리 그래도 너무 심했다는 논란이 더해지면서 꽤나 시끄러웠다.

큰 논란에도 스웨덴 사람들은 사실이라고 담담하게 말했다고..
